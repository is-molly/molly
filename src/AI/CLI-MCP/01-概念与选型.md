# 概念与选型

Claude Code 接外部能力，常见三条路：**内置**、**Bash + CLI（常配 Skill）**、**MCP Server**。排顺序：先用内置，不够再用 CLI，最后才考虑 MCP。

## 三层：内置、CLI、MCP

### 第一层：内置

改代码、搜仓库、跑 shell，一般不需要 MCP。

| 工具 | 干什么 |
|------|--------|
| Read / Write / Edit | 读写项目文件 |
| Bash | `git`、`docker`、`kubectl`、`npm` 等 |
| Grep / Glob | 仓库内搜索 |

**Filesystem MCP** 对 Claude Code 无意义——与内置读写重复。**Sequential Thinking MCP** 也不要装，用 Skills（如 Superpowers）代替。

权限、沙箱：[Claude Code 第 5 章](/AI/Agent/ClaudeCode/第5章%20权限、沙箱与AutoMode.html)、[第 10 章](/AI/Agent/ClaudeCode/第10章%20终端命令执行.html)。

**内置不够时：** 要操作 Gitee 上的 Issue、PR 等**平台 API 对象**，而不是仓库里的某个文件。

### 第二层：CLI

<a id="cli-通道"></a>

不注册 MCP，让 Claude Code 用 **Bash** 跑已有命令；**Skill** 或 `CLAUDE.md` 写清触发条件与命令格式。任务匹配时模型走 Bash，输出进对话。

**为何 coding agent 常优先 CLI：**

| | Bash + CLI | MCP |
|--|------------|-----|
| 进入上下文 | 一条命令 + 输出 | 每个 tool 的 schema + 可能很大的返回体 |
| 维护 | `--help`、官方文档 | 跟 Server 版本、tool 列表 |

Context7、Playwright 上游都明确推荐 **CLI + Skill**（深潜见 [03](03-Context7-CLI.md)、[04](04-Playwright-CLI.md)）。`docker ps`、`kubectl logs`、`mysql -e`、`git push` 也通常停在本层。

**Bash 注意：** 可在 `settings.json` 预批准常用命令；生产库用只读账号；终端 `!` 可直接跑 shell。

**Skill 与 CC Switch：** Skill 说明「何时跑哪条命令」；CC Switch 管 `skills sync`（详见 [Skills 02](../Skills/02-管理架构与快速上手.md)）。Plugin（含自带 MCP）用 Claude Code `/plugin`，不走 CC Switch Skills 面板。

**用 CLI 就够的典型领域：**

| 领域 | 示例 | 何时改用 MCP |
|------|------|--------------|
| 本地 Git | `git log`、`git push` | Gitee/GitHub **网页侧** Issue、PR |
| Docker / K8s | `docker logs`、`kubectl get` | 一般不需要 |
| MySQL / Redis | 客户端一条命令 | 一般不上 DB MCP；Postgres **调优** 见 [06 Postgres MCP](06-Postgres-MCP.md) |

### 第三层：MCP

<a id="mcp-通道"></a>

[MCP](https://modelcontextprotocol.io/) 是 Claude Code 与 **MCP Server** 之间的协议：Server 暴露 **tools**，模型按名调用，Server 调外部 API。

| | Skill | MCP |
|--|-------|-----|
| 形态 | `SKILL.md` 指令 | 独立进程或 Remote 服务 |
| 触发 | 描述匹配 / `/skill` | 模型 tool call |
| 典型 | 流程、规范 | 平台 API（Issue、PR） |

**常见理由：** Remote MCP（Gitee、GitHub）、OAuth 一次登录多 tool 共用、git 管不了的对象（PR Review 等）。

**传输与配置：**

| 方式 | 说明 |
|------|------|
| **stdio** | 本地子进程，如 `npx @playwright/mcp` |
| **Streamable HTTP** | Remote URL + PAT/OAuth（当前推荐） |

配置在 `~/.claude.json` 或项目 `.mcp.json`；`claude mcp add` / `add-json`；会话内 `/mcp`、`claude mcp list` 验证。OAuth：`claude mcp login <name>`。CC Switch：GUI 表单，或 CLI `mcp add`（**$EDITOR 改 JSON**）→ `mcp sync`（细节 [02 章](02-安装与快速上手.md)）。

**代价：** 每个 MCP 占 context（tool schema）。能少装就少装；Gitee/GitHub 可收窄 toolset（[05 章](05-Gitee与GitHub-MCP.md)）。

**Remote vs 本地 stdio：** Gitee、GitHub 优先 Remote；Playwright 优先 CLI（MCP 备选见 [04 章](04-Playwright-CLI.md#playwright-mcp-fallback)）。**不要**同一逻辑 Remote + stdio 双份同名 server。

**通常不必装：** Filesystem、Sequential Thinking、archived reference 里的 Fetch/Memory/Git（用内置 / WebFetch / `git` 即可）。

## 选型

装任何东西之前，对一下表：**内置、CLI，还是 MCP**。

### 三条规则

<a id="三条规则"></a>

1. **本地一条命令能搞定的，不上 MCP**
2. **有适合 coding agent 的 CLI + Skill，优先 CLI**（Context7、Playwright）
3. **MCP 留给平台 API + 鉴权 + 内置/CLI 没有的能力**

### 按任务对照

| 任务 | 用什么 | 备注 |
|------|--------|------|
| 改代码、搜仓库 | Read / Write / Edit / Grep | |
| `git commit`、`git push` | Bash | 只管本地 git |
| Gitee Issue / PR | **Gitee Remote MCP** | [05 章](05-Gitee与GitHub-MCP.md) |
| GitHub 协作 | GitHub MCP 或 **`gh`** | 主用 Gitee 时常开 Gitee 即可 |
| 查库文档 | **ctx7 CLI** | MCP 备选 [03 · 章末](03-Context7-CLI.md#mcp-fallback) |
| 验 UI | **Playwright CLI** | MCP 备选 [04 · 章末](04-Playwright-CLI.md#playwright-mcp-fallback) |
| `docker` / `kubectl` | Bash | |
| Postgres EXPLAIN / 索引 | Postgres MCP Pro | [06 章](06-Postgres-MCP.md) |
| 架构 brainstorm | Skills | 不要 Sequential Thinking MCP |

<a id="不要重复装"></a>

### 勿双装

| 组合 | 建议 |
|------|------|
| ctx7 CLI + Context7 MCP | 只留 CLI |
| Playwright CLI + Playwright MCP | 只留 CLI |
| Gitee Remote + 本地 gitee stdio | 只留 Remote |
| Gitee + GitHub MCP 全开 | 主平台常开，另一个按需 + 缩 toolset |

<a id="和-skills-03-怎么加-cli--mcp"></a>

### 与 Skills 03 方案

| Skills 方案 | 建议增加的 CLI / MCP |
|-------------|----------------------|
| A 单人全栈 | Gitee MCP；ctx7 CLI；Playwright CLI |
| B 团队 | 同上；Gitee 可进 `.mcp.json` |
| C 快速原型 | ctx7 CLI；Gitee 按需 |
| D 最少 | 仅 Gitee MCP |
| E 省 token | ctx7 + Playwright CLI；不装对应 MCP |
