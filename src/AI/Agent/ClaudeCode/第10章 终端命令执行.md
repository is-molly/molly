# 终端命令执行

## Bash 工具

Claude Code 的核心能力之一是通过 **Bash 工具**在你的终端中执行命令。Claude 可以运行构建脚本、运行测试、安装依赖、操作 Git、读写文件系统等。

### 能力范围

Bash 工具可以执行几乎任何 Shell 命令，包括：
- 运行 npm / yarn / pnpm / pip 等包管理器
- 编译、构建、测试
- 操作文件系统（mkdir、cp、mv、rm 等）
- 调用 curl、wget 等网络工具
- 执行脚本
- 管道操作

### 权限控制

每次 Bash 命令执行前，默认会根据权限模式决定是否需要用户确认。可以通过权限规则预先批准常用的安全命令：

```json
{
  "permissions": {
    "allow": [
      "Bash(npm run *)",
      "Bash(npm test *)",
      "Bash(git status)",
      "Bash(git diff *)",
      "Bash(git log *)"
    ],
    "deny": [
      "Bash(curl *)",
      "Bash(rm -rf *)",
      "Bash(sudo *)"
    ]
  }
}
```

## 危险命令检测

Claude Code 内置危险命令识别机制，对于 `rm -rf /`、`sudo`、`chmod 777` 等高风险命令，即使权限模式允许也会触发额外警告。

Claude 自己也会在执行前分析命令的安全性——无需额外配置。

## PowerShell 工具（Windows）

从 v2.1.126 起，Windows 上的 Claude Code 可以将 PowerShell 作为主 Shell（而非回退到 Bash）。

### 启用方式

```shell
claude --tools "Bash,Edit,Read,PowerShell"
```

或通过环境变量：

```shell
export CLAUDE_CODE_USE_POWERSHELL_TOOL=1
```

### 检测与兼容性

- PowerShell 7 通过 Microsoft Store、MSI 或 .NET global tool 安装的版本都能被检测
- 启用 PowerShell 工具后，Claude 将其视为 Windows 上的主 Shell
- Skills 的 frontmatter 中可设置 `shell: powershell`，让 Skill 内的行内命令走 PowerShell

## 终端兼容性

Claude Code 的全屏模式（alternate screen）在以下终端中经过完整测试和适配：

| 终端 | 兼容状态 |
|------|----------|
| iTerm2 | 完全兼容，支持图片粘贴 |
| WezTerm | 完全兼容，`Shift+Enter` 无需手动配置 |
| Kitty | 完全兼容，修复了退出后键盘模式和 OSC 9 通知问题 |
| Ghostty | 完全兼容，修复了退出后 Ctrl+C 问题 |
| Windows Terminal | 完全兼容 |
| VS Code 集成终端 | 兼容，修复了滚轮速度问题 |
| JetBrains 2025.2+ 终端 | 兼容 |

### 禁用全屏模式

如果你更喜欢终端原生滚动（传统终端行为），设置：

```shell
export CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1
```

### 键盘增强模式

Claude Code 默认启用键盘增强模式（keyboard enhancement）以支持更多快捷键。退出时自动恢复终端模式。

## 环境变量持久化

SessionStart Hooks 支持通过 `CLAUDE_ENV_FILE` 将环境变量持久化到会话的所有后续 Bash 命令中（详见第 14 章）。

## 非交互模式下的命令执行

在 `-p` 模式中，Claude 同样可以执行 Bash 命令：

```shell
# 分析日志
tail -200 app.log | claude -p "Slack me if you see any anomalies"

# CI 中自动翻译
claude -p "translate new strings into French and raise a PR for review"

# 批量安全审查
git diff main --name-only | claude -p "review these changed files for security issues"
```
