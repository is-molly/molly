# 故障排查

## 启动问题

### `claude` 命令找不到

- Native Install 后重新打开终端
- 检查 `~/.local/bin` 是否在 PATH 中

### 登录超时

WSL2、SSH、容器等无法打开浏览器的环境，可用粘贴模式：

```shell
claude auth login
# 将浏览器中的 OAuth 验证码粘贴到终端
```

### 启动卡空白

如果网络慢导致账户设置请求超时，启动可能卡住 15 秒（v2.1.181 已修复）。

### macOS 打开文件失败（error -600）

v2.1.181 已添加 Apple Events 权限，修复了 `open`、`osascript` 和浏览器认证流的问题。

## Context 问题

### Context 超限

**现象**：`Prompt is too long` 错误

**解决：**

```
/compact
```

压缩当前对话，释放上下文空间。如果 compact 本身因为对话过大无法完成，需要 `/clear` 重来。

### 自动 compact 失败

**现象**：1M 上下文的会话被错误地阻止

**原因**：autocompact 窗口配置小于实际 API 限制（v2.1.128 修复）。

### 优化上下文使用

- 使用 Subagent 处理大量文件探索（不污染主会话）
- 在 CLAUDE.md 中只保留必要信息
- 定期 `/compact`

## MCP 连接问题

### MCP Server 连接失败

```
/mcp
```

检查 MCP Server 状态。重连时工具列表按前缀汇总，不再刷屏。

### MCP 工具数为零

Server 连接成功但没有工具——检查 Server 端日志，确认工具注册正常。

### OAuth 认证问题

MCP OAuth 遵循 RFC 9728 标准，v2.1.181 优化了视觉和自动关闭体验。

## 终端兼容性问题

### 滚动速度异常

VS Code / Cursor 终端中滚轮速度问题已在 v2.1.132 修复。

### 退出后键盘异常

Ghostty、Kitty、WezTerm 退出后 Ctrl+C 不响应——v2.1.85 修复。

### Unicode / Emoji 损坏

v2.1.132 修复了工具错误截断导致的 emoji 损坏、Indic 连字和 ZWJ emoji 的光标定位问题，以及 vim 操作符损坏分解重音字符（NFD）的问题。

### 全屏模式问题

系统睡眠唤醒后全屏模式显示异常——v2.1.132 修复。如仍有问题：

```shell
export CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1
```

## 文件编辑问题

### 网络驱动器上 Write/Edit 产生 0 字节文件

v2.1.181 修复了网络驱动器和云同步文件夹上文件截断的问题。

### 受保护目录写入被阻止

需要修改 `.vscode/`、`.git/` 等受保护目录时，需要显式确认。使用 `--dangerously-skip-permissions` 可以跳过这些提示（v2.1.126 扩展了覆盖范围）。

## 性能优化建议

- **模型选择**：日常任务用 Sonnet，复杂规划用 Opus，简单搜索用 Haiku
- **Effort 调优**：简单任务降低 Effort 等级以减少 Token 消耗
- **Worktree 隔离**：并行不相关的任务
- **Subagent 委托**：将搜索和探索委托给 Explore 子代理
- **定期 `/compact`**：长会话中定期压缩上下文
